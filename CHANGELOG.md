# Changelog

## 0.2.0 — 2026-10-20 · community preview

- Reuse the original CSSM-HI backend and Nuxt user workbench, with self-hosted storage, packaged prompts and generated local credentials.
- Exclude the internal operations console and management APIs.
- Complete one real-model initial run: 5/5 probes and persisted responses; publish a no-key read-only case, screenshots and walkthrough.
- Restore missing Lombok constructor-qualifier configuration for separate knowledge-database routing.
- Update Nuxt, Vue and ECharts security dependencies. Document remaining preview limits and dated security findings.


## 0.1.0 — 2026-10-19

First standalone community release, licensed under Apache-2.0.

- Explicit six-dimensional question labels, compatibility checks and deterministic greedy state-pair coverage selection.
- Guided human annotation of raw questions, with unvalidated suggestions requiring confirmation.
- Imported answer evidence with entrypoint, source, timezone-aware capture time and citations.
- Self-contained interactive HTML and JSON reports: selection comparison, per-question coverage gains, filters, search and evidence inspection.
- Fictional runnable example, browser screenshots, short walkthrough and English/Chinese documentation.

Python 3.9+; no third-party runtime dependencies or provider calls. State-pair coverage is a design metric. The example is not an algorithm-effectiveness benchmark or an estimate of consumer visibility.
