Run the full workbench · 运行完整系统
View source →
The open-source package includes the existing Nuxt user application, Spring Boot backend, CSSM-HI generation, model execution, saved answers and run history. The author's operations console stays private.
git clone https://github.com/ZaneLau/traclux-probe.git
cd traclux-probe
python3 scripts/community_init.py
# Privately configure MODEL_* in .env
docker compose up --build -d
Open http://localhost:3100/login with the credentials generated in your local .env. Your model account supplies quota; this public demo makes no model calls.
