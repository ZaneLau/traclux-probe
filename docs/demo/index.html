Method & limitations · 方法与边界

Each question has six manually supplied state labels. Greedy selection adds the most previously uncovered state pairs; ties preserve input order. A larger pair count does not demonstrate higher answer quality, user-demand coverage, or client visibility. Imported provenance is a supplied record, not independently verified. 每题标签由输入者提供，不能视为对用户真实心理状态的验证。
