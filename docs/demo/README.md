# Explore the demo / 打开演示

This is an offline, fictional example generated by the real community CLI. It does not call a model or estimate real brand visibility.

**[Open the live demo](https://zanelau.github.io/traclux-probe/demo/)**, or download the repository and open `docs/demo/index.html` in a browser. No installation, account or API key is needed. GitHub's HTML file viewer displays the source instead of running it.

下载仓库后，直接用浏览器打开同目录的 `index.html`。这是可操作的离线报告，不需要安装依赖或登录。品牌、问题与答案均为虚构。

If your browser does not associate HTML files correctly, run this from the repository root and visit [the local demo](http://127.0.0.1:8769):

```bash
python3 -m http.server 8769 --bind 127.0.0.1 --directory docs/demo
```

Stop that optional server with Ctrl+C after viewing.

## What to try

3. Click Q02 in the input-order row. It was not selected by CSSM-HI and has no imported answer; neither fact means it is unimportant.
4. Search the questions, switch selection filters, or download the original JSON report.

## Rebuild

From the repository root, generate both artifacts from the same run:

```bash
python3 -m traclux_probe \
  --questions examples/fictional-brand/questions.json \
  --responses examples/fictional-brand/responses.json \
  --brand 星屿 --budget 5 \
  --output docs/demo/report.json --html docs/demo/index.html
```

The embedded report in `index.html` matches `report.json`; only the generation time changes between runs. The HTML adds the complete candidate pool, all imported responses and derived coverage details for offline exploration.

## Design scope

The owner approved using the inspected Promptfoo web viewer as a reference instead of generated concept images. Adopted: compact comparison, filterable question list and evidence detail. The implementation uses native HTML buttons, search, disclosure and download, with self-contained CSS and JavaScript to preserve the Python-only, zero-dependency entry path. There is no frontend framework or remote font/asset dependency.

Sources: [Promptfoo viewer](https://www.promptfoo.dev/docs/usage/web-ui/), [Langfuse example project](https://langfuse.com/docs/demo). These are design references, not endorsements or effectiveness evidence.

Local verification (2026-10-17): checked overview → question → contribution → supplied answer/source/time in Chromium; tested all filters, search and empty results, exact JSON-download equality, offline interactions and 390px layout without horizontal overflow. The main screenshot uses a 1440px viewport. Eight Python tests passed, including coverage reconciliation, absent answers and script-termination escaping. No external requests were observed. Owner visual acceptance and public hosting remain pending.
