Run the full workbench · 运行完整系统
View source →
Deploy the Nuxt workbench and Spring Boot backend to generate new probes, run them against your model and inspect answers and run history.
git clone https://github.com/ZaneLau/traclux-probe.git
cd traclux-probe
python3 scripts/community_init.py
# Configure MODEL_* in .env
docker compose up --build -d
Open http://localhost:3100/login with the credentials generated in your local .env. Your model account supplies quota; this public demo makes no model calls.
