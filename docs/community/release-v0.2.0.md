# Traclux v0.2.0 — community preview

Traclux is now the self-hosted CSSM-HI probe generation and execution system, including its existing user workbench and supporting backend.

Start with a brand and category, generate probes, connect your own model, execute them and inspect saved results. The release includes the Java/Spring Boot engine, Nuxt user app, ordinary-user authentication, isolated databases, packaged prompts and Docker Compose setup. The author's internal operations console, model accounts and production data are excluded.

- [Explore the real-model case](https://zanelau.github.io/traclux-probe/demo/) — no signup or API key.
- [Run it locally](https://github.com/ZaneLau/traclux-probe#start-locally).
- [Read the known limitations](known-limitations.md) and [security review](security-review.md).

One Anker / USB-C charger run completed 5/5 probes in 173 seconds and saved five raw responses. It verifies execution, not algorithm superiority, live-web evidence, consumer-client visibility or meaningful brand ranking.

This is an early community preview. Grouped question/answer presentation, topic mapping, summary wording, manual re-execution and call accounting have known gaps. Default deployment is local-only; external model usage belongs to your provider account. Do not expose the instance as an untrusted public service.

The earlier Python selection utility remains available as an auxiliary tool and in v0.1.0 history. It no longer defines the main product.
